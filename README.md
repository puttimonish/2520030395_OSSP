## 💻 Example Compilation & Execution

C programs can be compiled using GCC:

```bash
gcc fork.c -o fork
./fork
```

Example for an `exec()` program:

```bash
gcc exec.c -o exec
./exec
```

C source files can be opened and edited using:

```bash
nano filename.c
```
